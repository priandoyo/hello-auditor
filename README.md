# Hello Auditor

**A learning project exploring IT Governance, Software Testing, DevOps, and CI/CD for IT Auditors.**

Hello Auditor is a practical learning project designed to introduce IT auditors to software testing, test automation, and DevOps practices. It explores how technical knowledge can support IT governance, control assessment, software assurance, and continuous monitoring.

The project aims to bridge the gap between traditional IT auditing and modern software development practices.

> **Project Status: Work in Progress**
>
> This repository is currently under development. New features, testing scenarios, automation capabilities, and DevOps practices will be introduced progressively.

## Objectives

The project aims to help IT auditors understand:

- **IT Governance:** Understanding how technology development and operational practices relate to governance, risk management, and internal controls.
- **Software Testing:** Learning how to validate application functionality through positive testing, negative testing, and other testing techniques.
- **Test Automation:** Understanding how automated tests can provide repeatable and consistent testing evidence.
- **DevOps:** Exploring the integration of development, testing, and operational practices.
- **CI/CD:** Understanding how Continuous Integration and Continuous Delivery/Deployment pipelines automate software testing and delivery.
- **IT Audit:** Exploring how technical testing and automation can support IT audit procedures and control assessments.

## Learning Areas

The project will progressively explore the following areas:

### 1. IT Governance and Control

Understanding the relationship between software development practices, IT controls, risk management, and governance frameworks.

### 2. Software Testing and Test Automation

Learning how to design test scenarios, execute automated tests, validate expected results, and identify application defects.

### 3. DevOps and CI/CD

Exploring how software development and operational activities can be integrated through automation.

Topics include:

- Continuous Integration (CI)
- Continuous Delivery (CD)
- Continuous Deployment
- Automated Testing
- Build and Deployment Pipelines
- GitHub Actions

### 4. IT Audit and Continuous Assurance

Exploring how automated testing and DevOps practices can support IT audit activities, control validation, and continuous assurance.

## Project Direction

Hello Auditor is intended to evolve from a basic software testing exercise into a broader learning environment covering the intersection of:

**IT Governance + Software Testing + DevOps + CI/CD + IT Audit**

The objective is not to turn auditors into software developers, but to help them understand how modern technology works, how technical controls are implemented, and how those controls can be independently assessed.
